Compares two folders (added/removed/changed files), with a line diff for changed text files or a hex byte diff for changed binary files. In the desktop app, folders are picked natively and can be rescanned; in the browser, a plain folder-upload input is used for broad support (Chromium/Firefox/Safari) rather than the Chromium-only File System Access API.
